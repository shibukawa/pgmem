## 必要なもの

- Go 1.25 以降
- Go 用 PostgreSQL driver（ここでは pgx を使います）

module に pgmem と pgx を追加します。

```sh
go get github.com/shibukawa/pgmem
go get github.com/jackc/pgx/v5
```

## テスト内で PostgreSQL を起動する

サーバーを起動し、通常の pgx driver で接続してクエリを実行します。テストが終わると、サーバーとメモリ上のデータディレクトリは解放されます。

```go
package quickstart_test

import (
	"context"
	"database/sql"
	"testing"

	"github.com/shibukawa/pgmem"
	_ "github.com/jackc/pgx/v5/stdlib"
)

func TestPostgresIsReady(t *testing.T) {
	server, err := pgmem.Start(context.Background(), pgmem.Options{Database: "app"})
	if err != nil {
		t.Fatal(err)
	}
	t.Cleanup(func() { _ = server.Close() })

	db, err := sql.Open("pgx", server.DSN())
	if err != nil {
		t.Fatal(err)
	}
	t.Cleanup(func() { _ = db.Close() })

	var result int
	if err := db.QueryRowContext(context.Background(), "SELECT 1").Scan(&result); err != nil {
		t.Fatal(err)
	}
	if result != 1 {
		t.Fatalf("SELECT 1 = %d, want 1", result)
	}
}
```

`pgmem.Start` は PostgreSQL 18 をテストプロセス内で動かします。標準の PostgreSQL wire protocol を使うため、通常の driver と DSN で接続できます。

## 複数テストでデータベース状態を使い回す

テストスイートでは、template server に一度だけ schema と seed data を準備して snapshot を作り、各テストに独立した fork を渡せます。[Go のテストガイド](../guides/go/testing/)では `pgmemtest` fixture を、[Go の基本ガイド](../guides/go/basics/)では migration と driver の使い方を説明します。

ほかの言語を使う場合は、[Python](../guides/python/basics/)、[Java](../guides/java/basics/)、[Node.js](../guides/nodejs/basics/)のガイドへ進んでください。
