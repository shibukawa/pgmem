---
title: バージョン番号
description: pgmem の安定版は 1.X.Y、ベータ版は 0.X.Y で、X は同梱する PostgreSQL のメジャーバージョンです。
---

pgmem の安定版は **1.X.Y**、ベータ版は **0.X.Y** で番号を付けます。先頭の `0` はベータ版を表します。

| 部分 | 安定版 | ベータ版 |
|---|---|---|
| 先頭の番号 | `1` は安定版を表します。 | `0` はベータ版を表します。 |
| `X` | 同梱している PostgreSQL のメジャーバージョンです。新しい安定系列は `1.<X>.0` から始めます。 | 同梱している PostgreSQL のメジャーバージョンです。ベータ系列は `0.<X>.0` から始めます。 |
| `Y` | その PostgreSQL メジャー系列における pgmem のリリース番号です。 | その PostgreSQL ベータ系列における pgmem のリリース番号です。 |

PostgreSQL 18 の現行安定系列は **1.18.0** から始まり、現在は PostgreSQL 18.3 を同梱します。PostgreSQL 19 Beta 4 を使うベータ系列は **0.19.0** から始めます（`0.19` はその系列の略記です）。PostgreSQL 19 の正式リリース後、安定版系列は **1.19.0** から始めます。

- 同じメジャー系列内の PostgreSQL ポイントリリースでは、pgmem の `Y` を増やします。正確な PostgreSQL のバージョンはリリースノートと `SELECT version()` で確認できます。
- セマンティックバージョニングではありません。Go モジュールは `v1` のインポートパスのままで、互換性のない API 変更はリリースノートで告知します。
- Go モジュールのタグ、バイナリ、PyPI パッケージ、Maven アーティファクト、npm パッケージは常に同じ番号です。ラッパーは自分と番号の違うバイナリを拒否します。
