## Requirements

- Go 1.25 or later
- A PostgreSQL driver for Go (this example uses pgx)

Install pgmem and pgx in your module:

```sh
go get github.com/shibukawa/pgmem
go get github.com/jackc/pgx/v5
```

## Start PostgreSQL in a test

Start a server, connect with the ordinary pgx driver, and run a query. The server and its in-memory data directory are released when the test ends.

```go
package quickstart_test

import (
	"context"
	"database/sql"
	"testing"

	"github.com/shibukawa/pgmem"
	_ "github.com/jackc/pgx/v5/stdlib"
)

func TestPostgresIsReady(t *testing.T) {
	server, err := pgmem.Start(context.Background(), pgmem.Options{Database: "app"})
	if err != nil {
		t.Fatal(err)
	}
	t.Cleanup(func() { _ = server.Close() })

	db, err := sql.Open("pgx", server.DSN())
	if err != nil {
		t.Fatal(err)
	}
	t.Cleanup(func() { _ = db.Close() })

	var result int
	if err := db.QueryRowContext(context.Background(), "SELECT 1").Scan(&result); err != nil {
		t.Fatal(err)
	}
	if result != 1 {
		t.Fatalf("SELECT 1 = %d, want 1", result)
	}
}
```

`pgmem.Start` runs PostgreSQL 18 in the test process. It speaks the standard PostgreSQL wire protocol, so the code uses an unmodified driver and DSN.

## Prepare a database once for many tests

For a test suite, prepare the schema and seed data on a template server, capture a snapshot, and give each test an independent fork. The [Go testing guide](../guides/go/testing/) shows the `pgmemtest` fixture; see [Go basics](../guides/go/basics/) for migrations and driver options.

For other stacks, continue with the [Python](../guides/python/basics/), [Java](../guides/java/basics/), or [Node.js](../guides/nodejs/basics/) guide.
