A browser test talks to an HTTP server in another process. Changing the test process's `DATABASE_URL` cannot move that server's existing database pool. Give each Playwright worker its own pgmem server, fork, and application process. Pass the fork URL when spawning the app, then reset the same fork before each test. The app and its database connections stay alive throughout the worker.

## Worker-scoped app, test-scoped reset

The fixture below starts pgmem and the app once per worker. `prepare` runs the project's migrations and baseline seed before the fork is made. The automatic `resetDb` fixture restores that baseline before every browser test. `appUrl` is a worker fixture, so `page` tests in that worker reach the same app process.

```js title="test/fixtures.js"
import { test as base, expect } from '@playwright/test';
import { spawn } from 'node:child_process';
import { createServer } from 'node:net';
import { once } from 'node:events';
import { PgmemServer } from '@pgmem/core';
import { migrateAndSeed } from './prepare-db.js';

async function freePort() {
  const listener = createServer();
  listener.listen(0, '127.0.0.1');
  await once(listener, 'listening');
  const port = listener.address().port;
  listener.close();
  await once(listener, 'close');
  return port;
}

async function waitForApp(url, child) {
  for (let attempt = 0; attempt < 100; attempt++) {
    if (child.exitCode !== null) throw new Error('app exited before it was ready');
    try {
      const response = await fetch(`${url}/health`);
      if (response.ok) return;
    } catch { /* still starting */ }
    await new Promise((resolve) => setTimeout(resolve, 100));
  }
  throw new Error('app did not become ready');
}

export const test = base.extend({
  pgmem: [async ({}, use) => {
    const server = await PgmemServer.start({
      database: 'app',
      prepare: ({ url }) => migrateAndSeed(url),
    });
    try {
      const fork = await server.fork();
      try { await use(fork); }
      finally { await fork.close(); }
    } finally {
      await server.close();
    }
  }, { scope: 'worker' }],

  appUrl: [async ({ pgmem }, use) => {
    const port = await freePort();
    const url = `http://127.0.0.1:${port}`;
    const child = spawn(process.execPath, ['./src/server.js'], {
      env: { ...process.env, DATABASE_URL: pgmem.url, PORT: String(port) },
      stdio: 'inherit',
    });
    try {
      await waitForApp(url, child);
      await use(url);
    } finally {
      if (child.exitCode === null && child.signalCode === null) {
        child.kill('SIGTERM');
        await once(child, 'exit');
      }
    }
  }, { scope: 'worker' }],

  resetDb: [async ({ pgmem, appUrl }, use) => {
    await pgmem.reset();
    await use();
  }, { auto: true }],
});

export { expect };
```

`src/server.js` must listen on `PORT`, use `DATABASE_URL` when constructing its pool, and respond to `GET /health` once ready. `migrateAndSeed(url)` must close every connection it opens before `prepare` returns.

```js title="test/orders.spec.js"
import { test, expect } from './fixtures.js';

test('creates an order', async ({ page, appUrl }) => {
  await page.goto(`${appUrl}/orders`);
  await page.getByRole('button', { name: 'New order' }).click();
  await expect(page.getByText('Order created')).toBeVisible();
});

test('starts from the prepared database again', async ({ page, appUrl }) => {
  await page.goto(`${appUrl}/orders`);
  await expect(page.getByText('No orders')).toBeVisible();
});
```

<Aside type="caution">
Playwright can run test files concurrently within one worker only if you opt into parallel mode. Keep these tests sequential within each worker: one reset cannot isolate overlapping requests. Separate workers each have their own pgmem server, fork, and app process. Limit Playwright's `workers` count to what the machine can hold.
</Aside>

To use a different dataset, seed the worker fork, call `fork.snapshot()`, and reset with `fork.reset({ snapshot: seeded })`. Keep the seeded snapshot open until the worker finishes. For in-process HTTP tests, use [API tests](../api-testing/).
